# PLAYWRIGHT

This repository contains beginner-friendly JavaScript learning examples and prompt-engineering notes.

## Contents

- `00_chapter_Prompt_Eng/` — prompt-engineering examples and notes.
- `01_chapter_JS_Basics/` — JavaScript basics, including variables, output, and math.
- `02_JS_Keywords/` — examples using JavaScript keywords and valid identifier names.
- `03_JS_Operators/` — JavaScript operator examples, including assignment.

## Running an example

Install [Node.js](https://nodejs.org/) and run a JavaScript file from the repository root:

```sh
node 02_JS_Keywords/Object.js
```

`Object.js` demonstrates creating an object with properties and reading those properties with dot notation.

The identifier examples demonstrate names that may start with a letter, `_`, or `$`, and may contain letters, digits, `_`, and `$` after the first character.

Run the assignment-operator example with:

```sh
node 03_JS_Operators/Assignment_Operator.js
```

`Assignment_Operator.js` demonstrates assigning values with `=` and combining a string and a number with `+`.
